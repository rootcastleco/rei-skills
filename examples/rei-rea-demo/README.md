# REI REA Reproducible Demonstration (`examples/rei-rea-demo`)

This directory contains a complete, reproducible demonstration of **REI REA (Rootcastle Reverse Engineering Workbench)** integrated with **REI Skills**.

## Contents

- [`run_demo.py`](run_demo.py) — Generates two harmless, redistributable WebAssembly v1 binary fixtures and runs the REI REA CLI against them when the Python workbench is available.
- [`fixtures/telemetry-filter-v1.wasm`](fixtures/telemetry-filter-v1.wasm) — Harmless 116-byte WebAssembly v1 fixture (`SHA-256: a86707e622921126c88d3b27142cb9404320197c19c45ec4fb81a2a4e908949f`) importing `env.telemetry_emit` and exporting `calculate_crc`.
- [`fixtures/telemetry-filter-v2.wasm`](fixtures/telemetry-filter-v2.wasm) — Harmless 169-byte WebAssembly v1 fixture (`SHA-256: 766cc87ddc6f9df8964a05f2da01e7a0c8bf8b8370b53646d57b954b5b20ba59`) adding imported host function `env.audit_log_frame` and exported function `validate_packet_header`.
- [`DEMO_OUTPUT.json`](DEMO_OUTPUT.json) — Real JSON output captured from `rei-rea inspect`, `rei-rea deep`, `rei-rea diff`, `rei-rea plan`, and `rei-rea case verify`.
- [`FINDING_REPORT.md`](FINDING_REPORT.md) — Real Markdown case report generated by `rei-rea case report`.

## Reproducing the Demonstration

### 1. Generate or verify fixtures and run the demo script

```bash
python examples/rei-rea-demo/run_demo.py
```

### 2. Run the REI REA CLI directly (requires `rootcastle-rei-rea` v0.2.0+)

```bash
# Identify and hash the artifact without executing it
rei-rea inspect examples/rei-rea-demo/fixtures/telemetry-filter-v1.wasm

# Parse bounded WebAssembly v1 sections, imports, and exports
rei-rea deep examples/rei-rea-demo/fixtures/telemetry-filter-v1.wasm

# Compare structural changes across v1 and v2
rei-rea diff \
  examples/rei-rea-demo/fixtures/telemetry-filter-v1.wasm \
  examples/rei-rea-demo/fixtures/telemetry-filter-v2.wasm

# Route the artifact to compatible REI Skills
rei-rea plan examples/rei-rea-demo/fixtures/telemetry-filter-v2.wasm
```
